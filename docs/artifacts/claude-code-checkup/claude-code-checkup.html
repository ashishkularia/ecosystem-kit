Warnings

Findings without actions

05

One repo’s hooks are slow — not all of them

warning

The PostToolUse:Edit chain runs at a 2,124 ms median in mylantite across 625 runs, against 164 ms in homeassistant. Same engine, same three hooks, a thirteenfold gap. It tracks repo scale — 3,059 tracked files and a 2.1 MB memory directory versus 170 files — but that is correlation, not a profile.

An earlier read of this called it kit-wide. It isn’t; it is concentrated in one repo, which changes the fix from an engine change to a scaling question.

06

healthy

The skill listing totals roughly 3.0k est. tokens against a ~1% budget — ample headroom on a 1M-token model, so skill routing is not degrading. CLAUDE.md is 6,053 characters and entirely non-derivable policy: nothing to trim.
